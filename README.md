# Evelina Portfolio — V5 (SVG character)

This version replaces the Rive character with a custom lightweight SVG character. Its pupils follow the pointer across the page, the head tilts subtly, and the eyelids blink. There is no Rive dependency. The character is a stylized mascot, not an exact portrait.

## Run

```bash
npm install
npm run dev
```

## Verify

Move the pointer around the page: pupils should move toward it, with a smaller head movement. The character stays still for touch input and for reduced-motion users.

The featured-work art and contact details are placeholders and must be replaced before publishing.
